# Status das Requisicoes (cores) - Projuris

| Cor | Status | Significado |
|---|---|---|
| Amarelo | Aguardando aprovacao | Pendente analise do Juridico PicPay/Original. |
| Verde | Aguardando execucao | Aprovada pelo Juridico; aguardando pagamento pelo financeiro. |
| Vermelho | Reprovada | Consultar Historico. Nao da para reenviar -- cadastrar nova requisicao. |
| Cinza | Em requisicao | Necessario finalizar para enviar para aprovacao. |
| Preto | Finalizada | Pagamento efetuado; comprovante disponibilizado pelo financeiro. |
| Lilas | Devolvida para ajuste | Comentarios na guia Historico em detalhes. |

## Regras de ouro
- O escritorio NUNCA finaliza requisicoes (especialmente reprovadas) -- atualizacao automatica.
- "Finalizada" = passou por todo o fluxo, com comprovante (baixa por robo).
- Reprovada de analise recursal: APROVADA = parecer acolhido; REPROVADA = orientacao diversa do Juridico.
- Apos comprovante de pagamento: baixa provisoria no mesmo dia; nao encerrar ate o pagamento estar lancado em Custas, Acordo e Quitacoes.
