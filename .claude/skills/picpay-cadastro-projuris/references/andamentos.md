# Andamentos Obrigatorios no Projuris (rol taxativo)

Nomenclatura **exata** conforme o rol -- essencial para retirar pauta de audiencia e identificar status.

## Rol taxativo
| Categoria | Andamentos |
|---|---|
| Comunicacao processual | Citacao; Intimacao; Publicacao |
| Pecas e manifestacoes | Contestacao; Apelacao; Agravo de Instrumento; Embargos de Declaracao; Impugnacao; Resp; Rext |
| Eventos processuais | Pericia; Audiencia; Revelia; Transito em Julgado |
| Resolucao | Acordo; Acordo Extrajudicial; Dispensa Recursal |
| Decisoes | Sentenca; Acordao |

## Andamentos adicionais (criados em maio/2025 - uso obrigatorio)
| Andamento | Quando aplicar |
|---|---|
| Contestacao (Sem Subsidios) | Defesa Generica por falta de envio do dossie em tempo habil. |
| Contestacao (Subsidios Fora SLA) | Defesa Prejudicada por envio incompleto/sem tempo habil. |
| Dispensa Recursal Automatica | Caso que atende a regra de Dispensa das Diretrizes Recursais. |
| Recurso Automatico | Caso com indicacao de Recurso Automatico nas Diretrizes. |

Excecao a regra automatizada (ex.: parece dispensa mas ha motivo concreto para recorrer) -> abrir requisicao
de analise recursal para avaliacao interna.

## Como preencher
| Campo | Preenchimento |
|---|---|
| Data | Conforme tabela do andamento. |
| Hora | So em audiencia. |
| Duracao | Nao preencher. |
| Listar como andamento | Sempre marcar. |
| Relevante | So para audiencia e decisoes. |
| Evento | Conforme rol taxativo. |
| Instancia | Conforme a fase (cadastrar a instancia antes do andamento). |
| Publicacao | Nao preencher. |
| Detalhes / Instrucao | Decisoes/sentencas/acordaos: incluir SEMPRE o dispositivo. Outros: fato relevante quando houver. |

## Apensos
Para apensar, o processo a apensar deve ter pasta ja aberta. Aba "Apensos" -> "Adicionar" -> numero da pasta.

## Documentos da pasta
Aba "Documentos", data = data de inclusao. Documentos atrelados a peticao entram separados da peticao.
Padrao de nomenclatura: numeracao antes da nomenclatura, tudo em MAIUSCULAS.
Ex.: `1. PETICAO INICIAL` / `2. DOCUMENTOS INICIAL` / `3. CONTESTACAO` / `4. ATA DE AUDIENCIA INICIAL` / `5. SENTENCA` / `6. ACORDAO`.
